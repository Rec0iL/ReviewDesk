# Lessons

- **A chat needs its writing box at the bottom.** (2026-11-16, item threads as a chat) I placed the
  round's note as an editable bubble at the time it was first written; the user then typed into
  an old bubble above Claude's newer reply, and a verdict change recoloured it. Rule: in anything
  that reads like a conversation, what the user writes next always starts in one input at the
  bottom and lands as a new entry below the last one; earlier entries are shown as written (edit
  on request, not as the place to type). Walk through "what does the user do next?" on the
  mock-up, not only "what does it show?".
